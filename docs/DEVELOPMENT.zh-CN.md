# CatMusic 1.26.0

一只爱听歌的猫。CatMusic 使用 Kotlin + Jetpack Compose + Media3 打造：本地曲库仍以私有副本保存在软件内，同时加入一个来自 MusicDL 轻听的「在线」页，可搜索、试听，并按自己需要的默认音质把喜欢的歌成批存进播放器。

## 功能

- **在线音乐（集成 MusicDL 轻听）**：底部「在线」页完整保留 MusicDL 的搜索与试听流程，一次检索网易云、QQ 音乐、咪咕、酷狗、酷我、千千静听、JOOX、5sing、Jamendo 九个公开来源；其中网易云、QQ、咪咕、酷我、千千与上游 musicdl 的默认音源一致。QQ 音乐改用官方移动搜索 `DoSearchForQQMusicMobile`，不再依赖会失效的旧桥接；搜索结果的 `size_128mp3 / size_320mp3 / size_flac / size_hires / size_new` 会直接显示 128K、320K、无损甚至母带体积。支持来源开关、最近搜索、封面与音质标签；播放页带进度、上/下一首、自动连播，兼容来源提供的 OGG / MP3 / M4A / FLAC 等流；歌词支持时间轴高亮、点击跳转。无需账号、无广告、无统计上报。
- **按 musicdl 的方式先解析、再显示真实大小**：搜索阶段就会为每个来源挑出最高可播放音质并探测真实文件，因此列表直接显示与桌面 musicdl 一样的体积，而不是按 320K 猜出来的小数字。网易云无损经常是 56 MB、115 MB 的 FLAC，酷我官方 FLAC 经常在 26–114 MB，千千 3000 档 FLAC 在 50–64 MB；咪咕会先尝试 SQ/ZQ，VIP 歌曲自动落到可播放的 320K MP3。无法解析出公开流的歌曲会像 musicdl 一样被过滤，而不是留下一个不能播的条目。
- **下载音质可选（默认无损）**：保存面板提供「标准 / 较高 / 无损」，默认档改为「无损」，与桌面 musicdl 的高音质优先行为一致。每个档位显示实际或预计体积；选择后会重新按档位解析。网易云使用 128K / 320K / FLAC，酷我使用官方 128K / 320K / FLAC（废弃了经常 410 的旧 FLAC 接口），酷狗使用标准 / HQ / SQ 哈希，QQ 通过 vkeys 的整数档位依次尝试母带（14）/ 臻品空间音频（13）/ 杜比（12）/ Hi-Res（11）/ SQ 无损（10）/ HQ（9）/ 320K（8）/ 128K（6），咪咕按 LQ / PQ / HQ / SQ 排序并优先 SQ/ZQ，千千使用 3000 / 320 / 128 档，JOOX 使用 MP3 128 / 320 / FLAC，5sing 使用 LQ / HQ / SQ，Jamendo 保持公开流。接口没有对应档位时自动降级并把档位置灰，不会把 MP3 标成无损。
- **搜索结果页设置默认音质**：搜索结果标题下方新增「默认下载音质」栏，可一次选择标准 / 较高 / 无损；默认「无损」，之后每首歌的下载都会按这个音质开始解析，不必逐首重选。默认值写入 WebView localStorage（`catmusic.defaultQuality.v2`），离开在线页、切回标签或重新打开应用后仍会保留；某首歌没有该档位时会在保存面板里自动降级并置灰，下一首仍按你设置的默认档位尝试。单首歌在保存面板里的临时切换不会改动搜索页的默认值。搜索行的体积也会随默认档位刷新。
- **下载前选择保存位置**：点下载按钮会先弹出保存面板，显示封面、曲名、歌手、音质与文件大小，并默认选中「存入播放器」。选择「存入播放器」会把音频、封面和可用歌词一起写入 CatMusic 私有目录并加入音乐馆，可直接离线播放、统计、使用音浪；选择「仅保存到音乐 / CatMusic」则沿用系统 DownloadManager，文件可在文件管理器中找到，但不会加入音乐馆。勾选「同时加入歌词」时，LRC 会随歌曲一起保存；来源没有歌词时会明确提示。
- **在线页与本地播放互不干扰**：切到「在线」或切换其他标签都不会打断本地播放，本地队列会在后台继续。只有在线试听真正开始（页面里的 HTML5 `audio.play()` 成功触发）时，才通过 Media3 自定义命令让本地播放器短暂淡出后暂停，避免两套播放器同时出声；仅仅浏览搜索结果不会暂停本地音乐。离开「在线」页会销毁 WebView 并停止在线音频，本地播放状态仍然保留。存入播放器使用应用私有副本，加入音乐馆后与本地导入歌曲遵循同一套删除语义；仅保存到公共目录的文件仍由用户自行管理，也不会改动设备上的任何原文件。
- **MusicDL 风格的简洁界面**：主界面、底部导航与设置页统一换上 MusicDL 的墨黑 + 柠檬绿配色，标题层级、留白和圆角更克制。品牌字标、空状态和导航选中态都改为直接、清楚的表达；在线页本身使用 MusicDL 原版 UI，与本地页共享同一套色彩语言。
- **全局沉浸式全屏**：整个 App 像游戏一样隐藏系统状态栏（时间、电量、信号等），只保留内容本身；从屏幕顶部下滑仍可临时唤出状态栏查看时间，回到 App 后自动隐藏。应用窗口仍然避让挖孔与手势区域。
- **防误触进度条**：歌词页和播放页的进度条不再“碰到就跳”。只有在细线上轻点，或先横向拖动超过一定距离，才会改变播放位置；在进度条附近空白处误触、竖向滑动都不会跳歌或跳进度。拖动时圆点会放大提示。
- **原版 3D 音浪歌词页**：打开音浪后，全屏歌词页会直接运行 Sonic Topography 的 Three.js 体素地形与 GLSL 着色器，而不是近似还原。数万个实例化方块随八个解码频段起伏，低频抬起中央高原，中频形成流动与尖峰，高频点亮边缘与闪光，节拍推出涟漪；体素地形、星野与雾色会从当前专辑封面提取主色，渐变到同色系的夜色中，歌词浮在地形上方。
- **随封面变色的音浪**：歌词页会读取当前歌曲封面（含自定义封面）的主色，用同一色相重建地形的亮部、暗部、雾色、涟漪与星尘/微尘颜色；切换歌曲时颜色平滑过渡。没有封面的歌曲使用其固定主题色，灰度封面会保留默认的紫靛夜空。
- **可切换的万点 3D 粒子音浪**：音浪菜单「音浪效果」可在原版 Three.js 体素地形与新的 WebGL 粒子球之间切换，选择保存在本机（WebView localStorage `catmusic.soundfield.effect.v1`），关闭歌词页、切歌或重启应用后仍然生效。粒子球由 **10,000 个光点**（100 经线 × 100 纬圈）组成，按球面 UV 从当前专辑封面（含自定义封面）逐点取色；球面映射采用不镜像的方向，拖动旋转时封面图案跟随手指自然转动，不会左右翻转。八个解码频段与音乐电平让球壳持续呼吸、外扩，鼓点用弹簧包络炸成空心云团再回吸；暂停后回到可辨认的封面色球体。单指拖动旋转、双指张合缩放，菜单里的「重置歌词视角」会同时让粒子球回到正面。没有封面时使用歌曲主题色生成暖色粒子。
- **稳定的音浪菜单与可调歌词行数**：右上角三点打开居中的实色面板，包含标题、关闭按钮、手势说明、**音浪效果选择**、鼓点律动滑杆、陀螺仪灵敏度滑杆、歌词行数滑杆（3–10 行）、陀螺仪开关、重置视角、歌词校准、导入歌词、关闭音浪和返回封面。横屏时自动排成两列并完整显示；改行数会按舞台实际高度重新计算字号与行距，7 行或 10 行都能在横屏里完整排开，选择会记住。切换效果时说明文字会同步改成对应操作提示，粒子模式还会提示颜色来自当前封面。
- **完整的歌词页交互**：顶部返回 / 菜单、居中的双语歌词窗口、任意歌词跳转、底部播放/暂停、可拖动进度线、音浪开关，以及每首歌独立的歌词校准，全部由页面内的 HTML/JS 绘制，因此 WebGL 画面可以始终位于最底层，不会被原生控件遮挡。
- **随鼓点鼓动的歌词与粒子**：当前句和歌词平面会跟随鼓点明显缩放、提亮。驱动不再只依赖离散的节拍标记，而是把节拍与经过自适应增益的低频/超低频一起合成包络，因此普通流行歌里持续的低频和每一次鼓点都能推动歌词；WebView 音浪页和原生歌词页都支持。环绕场景的星空与方块微尘会同步胀亮，地形边缘升起短寿命光尘。强度在右上角三点菜单的“鼓点律动”滑杆中实时调整（0–100%，默认 65%），设置会记住。所有数据来自本地 PCM 分析，不额外申请权限。
- **环绕音浪视角（不进入地下）**：单指在歌词区域左右拖动可水平 360° 环绕；上下拖动则在一段受控的俯仰范围内移动，最低角度会按横竖屏、目标点和缩放实时计算，保证相机始终停在整片地形上方，不会钻到地面以下，也不会翻过头顶到背面。双指张合仍是 0.8×–2.2× 光学变焦，双指扭转改为 ±10° 的轻微画面倾角。歌词作为可读面板始终保持在音浪前方，随视角只做水平 22° / 垂直 14° / 翻滚 8° 以内的正弦柔化倾斜，因此旋转时仍居中、正面、可读；当前句还会随鼓点向观察者方向浮起。粒子球模式下，单指拖动改为旋转球体、双指张合改为缩放球体；球面采用非镜像映射，旋转时不会把封面左右翻转，歌词依然保持在粒子前方；轻点跳转与拖动手势照常区分。视角、缩放与倾角都会记住，菜单“重置歌词视角”可回到正面，并同时归零粒子球的旋转与缩放。
- **歌词陀螺仪（可开关、灵敏度可调）**：打开后由 Android 的方向传感器驱动歌词平面随手机姿态倾斜，关闭后平滑回到手动视角；菜单中显示“开 / 关 / 不可用”。新增 0–200% 灵敏度滑杆（默认 100%），越高同样手机倾角带来的歌词倾斜越明显；灵敏度、陀螺仪开关、拖动角度和鼓点强度都保存在本机。
- **原生歌词页保留**：关闭音浪时仍使用原有的暖锈色到冷灰蓝渐变歌词页；再次打开音浪会重新进入原版地形。播放页本身仍由 Compose 原生绘制，不使用 WebView。
- **导入即保存到软件内**：支持系统文件多选和整个文件夹递归扫描。导入时会把音频复制到 CatMusic 的私有目录，并读取标题、歌手、专辑和内嵌封面；之后删除或移动手机上的原文件，播放都不受影响。
- **歌曲 + 歌词 + 封面一次导入**：导入面板新增“一次性导入”，可以在同一个文件选择器中多选音频、`.lrc`/`.txt` 歌词和图片封面。页面会按规范化后的文件名自动配对，再尝试用歌曲内嵌标题匹配；`cover` / `folder` / `front` / `封面` 等命名的图片会作为同一文件夹的专辑封面复用。文件夹导入也会递归收集这三类文件并自动配对，导入结果会直接显示配好了多少份歌词和封面。
- **安全删除**：在软件中删除歌曲，只会删除软件内的音频副本、自定义封面、歌词缓存和歌单引用；手机上的原始文件永远不会被软件删除。
- **广泛格式**：MP3、FLAC、WAV、AAC、M4A、OGG、Opus、AMR、AIFF、MIDI、MKA、WEBM 等，由 Media3 / ExoPlayer 解码。
- **歌曲信息与编辑**：完整信息面板展示格式、时长、文件大小、文件位置、播放次数和聆听时长；可直接修改标题、歌手、专辑，修改会保存到软件并同步到各页面。文件位置卡片可区分“软件内音频副本”和导入时的“原文件位置”。
- **可编辑歌单**：创建、重命名、删除歌单，添加/移除歌曲，上下调整顺序，一键按歌单顺序播放。从音乐馆歌曲菜单也可以快速把歌曲加入多个歌单。
- **后台播放**：MediaSessionService + 通知栏 / 锁屏控制，切到后台继续播放。
- **封面主导的播放页**：专辑主色流动背景，大幅封面居中悬浮，曲名与歌手安静排在封面下方；播放、进度、歌词与音浪入口收进底部单行玻璃控制坞。横屏时使用左侧封面、右侧信息的开阔布局；背景只保留封面主色泛光、暗角与克制的微尘，不再绘制橙色音浪地形，标题字号与留白也一并优化。
- **双语歌词**：LRC 中同一时间戳的原文与翻译行会自动配对，原文使用大字号，翻译以较小字号紧随其下；当前句与翻译同时点亮。纯单语歌词、TXT 歌词和没有歌词时的占位画面也沿用同一套排版。
- **单曲歌词校准**：歌词页菜单中有“歌词校准”。当前歌曲可独立按 0.1 秒调整歌词偏移（`+` 表示歌词延后，`−` 表示歌词提前），设置随歌曲保存，切换歌曲不会串用；“归零”可恢复原始时间轴。
- **自适应封面配色**：封面播放页在后台以缩略图采样当前封面，为高亮色、发光和进度条生成柔和的同源色；没有封面时回退到内置暖色。
- **克制的音频联动**：封面页保留 PCM 驱动的轻声呼吸与微尘；横屏背景改为封面主色泛光，不再绘制音浪地形。它直接分析本地音频，**不需要麦克风或录音权限**，不保存音频、不联网上传。
- **快速打开网页栏**：设置页新增网页快捷栏，可保存最多 10 个常用网址。添加时可填写名称、自动补全并校验 `http/https` 地址，并从已安装浏览器中选择“系统默认”或指定应用打开；每个快捷卡片可以直接打开、点铅笔修改或删除。浏览器列表通过系统包管理器发现，网址只交给外部浏览器处理。
- **实时 QWEA0 液态玻璃（Liquid Glass 2.0）**：App 直接依赖并运行 GitHub 的 [QWEA0/Liquid-Glass-Android](https://github.com/QWEA0/Liquid-Glass-Android)（MIT，`com.github.QWEA0:liquidglass:v2.0.11`），而不是手绘仿制。主界面卡片、底部导航、迷你播放器、搜索框、导入按钮、播放器控制坞、顶部圆形按钮、网页快捷栏和选中的底部导航项全部由真正的 `LiquidGlassView` 绘制：API 33+ 的单 pass AGSL SDF 透镜、贴边压缩环、逐通道物理色散、随重力传感器移动的镜面高光。所有玻璃统一使用透明的 Clear 材质，深色染色降到最低，并始终启用 `enableDynamicBackground`，因此镜头每帧都会重新采样背后的真实画面。Compose 只在上方排版文字与图标，玻璃下方由原生 `GlassBackdropView` 以约 60 fps 绘制慢速缩放/视差、漂移的专辑色光晕、移动的白色高光与上升微尘；播放页不再用不透明黑底遮住它，打开播放页时主界面整体淡出，让这层动态背景成为玻璃内外共同的画面。触摸由透明子类完整交还 Compose，因此既没有把整套 UI 包进 `AndroidView`，也不需要把页面重写成 XML。API 33 以下自动回退到库的经典模糊/色差管线。
- **主界面现实时钟**：音乐馆右上角显示一枚克制的实时时钟，包含 24 小时时分与中文日期/星期，紧邻导入按钮且不会抢占标题的视觉重心；每到整分钟自动校准，锁屏或切换页面后回来会立即对齐。
- **定时暂停与淡入淡出**：播放页右上角菜单新增“定时暂停”，提供 15 / 30 / 45 / 60 / 90 分钟预设，也可输入 1–1440 分钟的自定义时长。倒计时在后台前台服务中运行，锁屏也会继续；最后最多 10 秒会平滑淡出音量再暂停，醒来或重新播放时从静音柔和淡入。应用内点击暂停也会先做短暂淡出。倒计时会显示在菜单和播放页顶部，可随时关闭。
- **全新应用图标**：自适应图标改用 MusicDL 的波形徽标——柠檬绿底色上五根不等高的黑色声波柱，与启动画面、应用内品牌标记保持一致；同时提供深色主题专用 monochrome 波形和旧系统 PNG 回退，圆角、圆形与主题图标共用同一套前景。
- **背景默认跟随播放专辑**：正在播放（或暂停仍选中）的歌曲会自动从封面提取一组简单颜色——深色底色、主色点缀和最亮高光——再绘制成覆盖全屏的柔焦渐变色场。封面图片本身不会被画进背景，也不会叠加星点、散景或线条，只留下专辑的色彩氛围；主界面、歌单、统计和设置页都会同步。没有封面时用歌曲自身的双色主题生成同色渐变。没有当前歌曲时才使用 DIY 背景。6 种预设（极光、液态流光、星海、暮色、薄荷、墨黑）和自定义图片由原生 `GlassBackdropView` 绘制成真正的可见背景与玻璃采样源；自定义图片会处理 EXIF、压缩复制到应用私有目录，再以柔焦和暗角融入，删除手机原图不影响显示。
- **赞赏支持**：设置页新增支持卡片，点击后显示微信赞赏二维码。二维码图片随 APK 打包在本地，打开时不会联网；赞赏完全自愿，不解锁任何功能，也不会改变本地数据。
- **音浪等级**：提供“轻 / 标准 / 沉浸 / 极致”四档，在「设置 → 播放体验 → 音浪等级」中调整。歌词页的 WebView 地形密度与粒子数量会随等级提高（实例网格约 1.8 万到 2.7 万根体素柱，星野与微尘约 7,700 到 27,200 点），并自动调节内部渲染分辨率，优先保持流畅。
- **3D 歌词帧率**：在「设置 → 画面与性能」中可选择 30 / 45 / 60 / 90 / 120 / 无限制。30 档最省电，无限制则跟随屏幕刷新率；低档位会保留完整画质，高档位才启用低帧率自动降分辨率保护。粒子球与 Three.js 地形共用这个帧率上限，避免在 120 Hz 屏幕上无意义地重复绘制一万个点。
- **更柔和的全屏场景切换**：封面播放页与全屏歌词页不再硬切，而是带轻微缩放、上浮和交叉淡入淡出；音浪开关引起的原生渐变歌词页与原版 Three.js 歌词页切换也会柔和过渡。
- **横竖屏适配**：相机与歌词排版都随屏幕方向改变。横屏呈现开阔的斜视地形，竖屏把地形放在歌词下方，让文字始终位于视觉中心；页面会避让状态栏、挖孔和导航栏。
- **自定义封面**：可以为任意歌曲选择本地图片，自动处理 EXIF 方向、居中裁切并压缩保存；支持一键恢复内嵌封面。
- **歌词支持**：导入 LRC 或 TXT，自动识别 UTF-8 / UTF-16 / GBK/GB18030；LRC 会随播放高亮并滚动，轻点任意歌词可跳转到对应时间。
- **聆听统计**：累计总时长、今日聆听、近 7 天趋势、每首歌的实际聆听时长 / 单曲长度 / 播放次数。
- **明确的上/下一首与循环状态**：点击“上一首”永远切换到上一首，不会因为播放超过几秒而变成“重头播放当前曲”。循环按钮会直接显示“列表 / 单曲 / 循环”文字，单曲循环时还有数字徽标，切换时通过底部提示再次确认当前模式。
- **可靠持久化**：媒体库、歌单、元数据修改、封面/歌词缓存、单曲歌词偏移、背景偏好与统计全部写入应用私有存储，播放服务在后台持续计时。
- **本地优先，在线可控**：没有广告、不需要账号，不会写入或删除设备上的原始音乐。Manifest 为「在线」页申请了 `INTERNET` 与 `ACCESS_NETWORK_STATE`；联网只用于该页的公开音乐检索、试听与下载，只发送搜索关键词，不上传本地曲库、封面、歌词、歌单或统计，也不含遥测。所有本地功能以及音浪歌词页都能完全离线使用：音浪 WebView 仍设置 `blockNetworkLoads = true`，不申请麦克风权限。网页快捷栏只通过 `ACTION_VIEW` 把网址交给用户选择的外部浏览器；为发现已安装浏览器，Manifest 中声明了 https/http 浏览器查询。在线接口由第三方公开服务提供，可用性与内容归属随平台变化。

## 使用

1. 打开应用，点击右上角 `+` 或空页面的“导入第一批音乐”。
2. 要连同歌词和封面一起导入，选择“一次性导入歌曲、歌词与封面”，在系统选择器里多选音频、LRC/TXT 和图片即可按同名自动配对；也可以只导入音频或整个文件夹。导入时会显示复制、配对与解析进度，副本会占用软件存储空间。
3. 导入完成后点击歌曲即可播放；底部的媒体栏可进入全屏播放页。
4. 封面播放页底部控制坞最左侧的“词”会打开全屏歌词页。默认的“音浪”开启时进入全屏音浪歌词页，默认显示粒子球，可在菜单里切换到原版 Three.js 地形；关闭音浪时进入暖锈渐变歌词页。
5. 歌词页顶部是返回与菜单按钮；底部左侧播放/暂停、中间细进度线、右侧音浪按钮。进度线需要在线上轻点，或按住后明显横向拖动才会跳转；在进度条附近空白处误触或竖向滑动不会改变进度。轻点任意时间轴歌词会跳转到该句；没有歌词时可点画面中央的“导入歌词”。
6. 歌词页菜单提供：音浪效果（粒子球 / 音浪地形）、鼓点律动强度、陀螺仪灵敏度、歌词行数（3–10 行）、歌词陀螺仪、重置歌词视角、歌词校准、导入 / 更换歌词、关闭音浪、返回封面。效果选择会记住。关闭音浪后会回到同曲的原生渐变歌词页；在原生页底部右侧再次点开音浪即可重新进入上次选择的效果。
7. 在音浪设置里先选择“粒子球”或“音浪地形”。选择粒子球时，单指拖动旋转球体，双指张合缩放，粒子颜色和明暗直接来自当前专辑封面，鼓点会让球体向外炸开后回弹；选择音浪地形时，单指左右拖动可水平 360° 环绕，上下拖动会在地面以上的一段俯仰范围内移动，相机不会钻到地下或翻到背面。两种模式下歌词都保持在音浪前方，只做很小的柔和倾斜跟随，因此旋转时仍正面居中；当前句随鼓点向观察者浮起，轻点歌词仍然跳到对应时间。横屏时在菜单里把“歌词行数”调到 7–10 行，可以看到更多上下文歌词。打开“歌词陀螺仪”后，手机姿态会让视角一起随动；“陀螺仪灵敏度”可在 0–200% 之间调整。所有效果设置（含缩放、行数与灵敏度）会自动记住。
8. 歌词校准页可用 `−0.1` / `+0.1` 单独微调当前歌曲的歌词时间；`+` 让歌词延后，`−` 让歌词提前，“归零”恢复。偏移按歌曲保存，切换歌曲会读取各自的值。
9. 播放页右上角菜单提供：更换专辑封面、歌曲信息、导入/更换歌词、定时暂停、音浪联动开关、横屏沉浸模式。定时暂停可选 15 / 30 / 45 / 60 / 90 分钟，也可以在下方输入任意 1–1440 分钟；播放页顶部会显示剩余时间。它由前台播放服务计时，锁屏也有效，结束前会淡出后暂停。音浪等级统一在「设置 → 播放体验」中调整。
10. 音乐馆歌曲的 `⋮` 菜单提供：播放/暂停、添加到歌单、歌曲信息、从软件中删除。
11. 在“歌单”页创建和编辑歌单：点进歌单可添加歌曲、调整顺序、移除歌曲或播放全部。在“统计”页查看累计时长、7 日趋势和单曲聆听数据。在“设置”页导入音乐、清空音乐库或重置统计，调整音浪等级和 3D 歌词帧率（30 / 45 / 60 / 90 / 120 / 无限制）。在“设置 → DIY 主界面”中可以切换预设背景或上传自定义图片；在“支持 CatMusic”卡片中可以打开微信赞赏码。
12. 底部「在线」页可以在九个公开来源中一次搜索。点来源圆片可临时关闭某个来源；点搜索框输入关键词，或点最近搜索 / 灵感卡片快速开始。搜索会优先解析并显示最高可用音质的真实大小，「默认下载音质」栏默认「无损」，之后每首歌点下载都会按这个档位开始，不需要逐首重设；设置会记住。点歌曲行开始试听；点行尾的下载按钮会打开保存面板，默认选中你的默认音质和「存入播放器」，仍可按需临时切换或勾选「同时加入歌词」，确认后显示音质解析、下载和入库进度。也可以改选「仅保存到音乐 / CatMusic」交给系统下载器。按返回键先关闭保存面板/歌词/播放页，再回到搜索页，最后回到本地音乐馆。
13. 在“设置 → 快速打开网页”中点击“添加网页”，填写名称和网址（可省略协议，自动补 https），然后选择“系统默认”或某个已安装浏览器；最多保存 10 个。点击快捷卡片直接打开，点击卡片右上角铅笔修改或删除。网址只交给外部浏览器；CatMusic 自身的联网仅发生在「在线」页。

## 歌词页音浪（WebView）

- **架构**：`NowPlayingScreen` 在 `showLyrics && audioReactiveOn` 时进入 `SonicLyricsScreen`。它是一个全屏 `AndroidView(WebView)`；HTML 里的 `<canvas id="scene">` 是 WebGL 地形，`<canvas id="particle-scene">` 是独立的 WebGL 点精灵粒子球，任意时刻只显示一个。所有歌词、菜单、进度条和校准面板都是同一页面里的 DOM，因此不需要把 Compose 控件叠在 SurfaceView 上，也不会有触摸穿透。
- **数据**：`AudioReactivePcmTap` 仍然在 Media3 音频管线中读取解码后的 PCM。Kotlin 每约 50 ms 把八个平滑频段、电平与节拍通过 `evaluateJavascript` 发给页面；歌词、播放位置、时长、偏移、曲目标题 / 歌手与安全区也由 Kotlin 发送。粒子球启动后，Kotlin 还会把当前封面压成 96×96 JPEG data URL，通过 `window.catmusic.artwork({data})` 发送给页面做逐点取色。页面从不接触音频文件。
- **交互**：页面通过 `CatMusicBridge` 调用 `ready / close / toggle / seek / setOffset / importLyrics / toggleAudioMode / setGyroEnabled`；启用陀螺仪后，Kotlin 通过 `window.catmusic.orientation` 推送 pitch / roll。在地形模式下单指拖动环绕音浪、双指张合缩放；在粒子模式下单指旋转球体、双指缩放球体；轻点歌词跳转，手势结束会抑制误触发的点击。播放、暂停、拖动进度、点击歌词、校准、音浪效果、地形视角、缩放、鼓点强度和导入都保存在本机，关闭音浪与返回封面仍走原生流程。
- **效果切换与记忆**：菜单里的「音浪效果」把选择写入 `catmusic.soundfield.effect.v1`，页面初始化时先读取它再显示对应画布，所以在关闭歌词页、切歌、销毁 WebView 或重启应用后仍然保留。切换时画布做 0.5 秒淡入；粒子模式提示文案、顶部手势说明和「重置歌词视角」的行为会同步切换。所有音频和封面数据仍留在本机。
- **离线与隐私**：页面只加载 `file:///android_asset/sonic/` 下的文件；这个 WebView 单独设置了 `blockNetworkLoads = true`。应用为「在线」页持有 `INTERNET` 权限，但音浪页无法发起任何网络请求，也不申请 `RECORD_AUDIO`。
- **渲染档位与帧率**：极致档使用 165×165 的实例网格（27,225 根体素柱）。页面按设置的帧率预算限制地形更新，默认 60 fps；30 / 45 档不会触发自动降分辨率，60 及以上如果持续低于 45 fps 才会逐级降低内部像素比，文字 UI 始终按屏幕分辨率保持清晰。分辨率初始上限按音浪等级为 1.5–2.0 倍。
- **相机与色调**：相机位置、网格间距、体素宽度和地形着色器均取自 Sonic Topography，并针对竖屏手机调整了视距与目标点；地形以紫色 / 靛蓝体素和月白峰顶为主，远处沉入深蓝雾中，节拍推送蓝白涟漪，高频带出青白色微闪，背景保留参考视频里暖褐与深蓝交界的夜色。
- **粒子系统**：地形场景常驻三层 Three.js Points——远景星野（随呼吸轻微闪烁）、围绕地形漂浮的方块微尘（逐帧上浮、摆动并回收）以及节拍触发的地形光尘。三层都使用本地 GLSL 的柔边方形点精灵与加法混合，颜色在冷白与暖白之间分布；鼓点会同时提高点径、亮度并生成新的短寿命粒子，暂停后自然回落到安静状态。粒子数量随音浪等级从约 7,700 到 27,200 点缩放，不影响歌词 DOM 的清晰度。
- **粒子球渲染**：`particle.js` 使用独立的 WebGL 点精灵管线渲染 **10,000 个点**（100 经线 × 100 纬圈）。每个点按球面 UV 从 96×96 封面缩略图逐点取色，再做适度的饱和度/亮度补偿；球面 UV 使用非镜像方向，面向相机时封面左侧对应屏幕左侧、右侧对应右侧，旋转时不会左右翻转。顶点着色器把球面坐标旋转、透视投影并绘制为圆形软边点精灵；八个频段、音乐电平和鼓点弹簧共同推动径向位移与逐粒子散布，形成参考图中的空心爆炸壳、环带和稀疏外缘。全屏背景由另一个片元着色器按封面暗部色和强调色绘制暗色暖调渐变及暗角，并随电平轻微呼吸。点数据只在首次加载或换封面时上传，之后每帧只更新 uniform；画布 DPR 上限为 2.0。选择粒子球时隐藏的 Three.js 地形暂停渲染，只保留歌词计时与进度更新；画布隐藏或页面不可见时停止 requestAnimationFrame。
- **双指缩放**：页面使用 Pointer Events 同时跟踪两个触点，按两指距离的变化做 0.8×–2.2× 的光学变焦，而不是把相机推进体素内部；因此放大后仍能看到完整的方块结构，也不会穿模。缩放与单指倾角一起写入 localStorage，点击“重置歌词视角”可同时归零。
- **封面取色**：Kotlin 的 `rememberArtworkAccent` 在 IO 线程上读取封面缩略图，按饱和度与明度加权抽样得到可读的主色，并通过 `window.catmusic.palette({accent})` 发送给页面。页面把 sRGB 主色转为 HSL，在保持暗部与月白峰顶可读性的前提下生成地形、雾、涟漪、星尘与微尘所需的一组颜色；颜色 uniform 在约 1 秒内交叉淡入，CSS 环境光也同步切换。无封面时沿用曲目的确定性主题色；低饱和封面回退到紫靛夜色。整个过程只读取软件内的封面副本，不联网、不上传。
- **菜单渲染兼容**：音浪菜单采用居中的实色面板，不再使用 `backdrop-filter`、顶角弹层定位和缩放动画，规避部分 Android WebView/GPU 组合下菜单只剩一条背景条的合成问题。横屏下说明、滑杆与六个操作项使用两列网格，整块面板可完整显示；面板内的关闭按钮与点击遮罩关闭都会恢复歌词手势。

## 在线音乐（MusicDL 集成）

- **来源与页面**：在线页完全运行在 APK 自带的 `app/src/main/assets/musicdl/www/` 本地页面中，保留 MusicDL 的 HTML/CSS/JS、最近搜索、来源开关与播放器 UI；页面通过 `Native` JavaScript 接口调用 `com.catmusic.app.online.MusicApi` 检索九个公开来源并解析可播放地址。歌名、歌手、封面、歌词与音频流都来自第三方平台。
- **播放方式**：试听由页面内的 HTML5 `<audio>` 完成，不经过 Media3，也不会创建后台媒体通知；离开「在线」标签会销毁 WebView 并停止在线音频。切到「在线」或切换其他标签时本地 Media3 继续播放；只有在线试听真正开始播放时，页面才调用 `Native.pauseLocalPlayback()`，让本地播放器淡出后暂停，避免两套播放器叠音。仅浏览搜索结果或打开在线页不会打断本地音乐。
- **大小显示**：搜索结果行直接显示下载体积，并按当前默认档位刷新。网易云在搜索阶段探测 999000 / 320 / 128 的 Meting 流并回写真实 `Content-Length`（常见 25–115 MB）；咪咕解析 SQ/ZQ 等格式并用实测大小覆盖声明值；千千对每条结果请求 3000 档并探测 FILE；酷我直接解析搜索接口的 `MINFO / N_MINFO`（含 FLAC、MP3、OGG 分档大小）；酷狗把 SQ/HQ/标准三档的 `FileSize` 一起保存，列表优先显示 SQ。5sing 使用 `songSize`，JOOX/Jamendo 等无法提前取得大小时按当前档位和时长显示“约 X MB”。保存面板中的分档提示与解析后的 `Content-Range` / `Content-Length` 精确值同步更新。
- **默认音质**：搜索结果标题下方的「默认下载音质」栏把选择写入 WebView 的 `localStorage`（`catmusic.defaultQuality.v2`），首次使用默认「无损」；`handleDownload` 以它作为每首歌的首选档位。切换默认档位时，当前结果行的体积也会立即按新档位刷新。切换标签或重新打开应用后会读取该值。每首歌的保存面板仍可临时切换，但不会反向修改默认值。
- **音质解析**：`MusicBridge.resolveQuality` 把 `standard / high / lossless` 传给 `MusicApi.resolve(trackJson, quality)`。网易云通过 Meting `br=128 / 320 / 999000` 尝试 MP3 128K、MP3 320K、FLAC；咪咕移植了 `MiguMusicClient` 的搜索、`listen-url/h5/v2.4` 解密与 128→320 路径替换，按 SQ/ZQ → HQ → PQ 尝试；千千移植了 `QianqianMusicClient` 的签名、`tracklink` 和 3000 / 320 / 128 / 64 档；酷我移植了 `KuwoMusicClientUtils` 的 DES 查询加密与官方 `convert_url2` 接口，优先 FLAC 再 320K MP3；酷狗使用 `FileHash / HQFileHash / SQFileHash`；QQ 依次选择 `song_play_url_standard / _hq / _sq`；JOOX 从“MP3 128、MP3 320、无损FLAC”等链接中按档位选择；5sing 选择 `lqurl / hqurl / squrl`；Jamendo 只有公开标准流。每次解析都会探测真实文件并回写 `quality`、`qualityLabel`、`ext` 和 `size`；高音质不可用时按档位向下回退，前端会把请求档位标为不可用并切换到实际档位。FLAC URL 即使被平台错误标成 `audio/mpeg`，也会按 `.flac` 和码率识别为无损。
- **下载方式**：下载地址先由 `MusicApi.resolveQuality` 解析，再弹出保存面板。选择「存入播放器」时，`MusicBridge.downloadToLibrary` 把音频流式写入缓存并通过 `onLibraryProgress` 上报进度；`OnlineLibraryImporter` 将音频移入 `files/music`、封面压缩到 `files/artwork`、LRC 写入 `files/lyrics`，再以稳定 ID 调用 `MusicRepository.addTracks` 加入音乐馆；歌曲来源名称会追加实际音质标签。选择「仅保存到音乐 / CatMusic」时继续交给 Android `DownloadManager`：名称格式为“歌手 - 歌名.扩展名”，未知扩展名回退为 `.mp3`；Android 10 及以上保存到公共 `音乐/CatMusic`，Android 8–9 使用应用专属外部音乐目录，因此不需要 `WRITE_EXTERNAL_STORAGE`。
- **网络与隐私**：搜索只把关键词和已选来源标识发送给公开接口；`MusicApi` 使用 `HttpURLConnection` 请求对应平台的公开网页/API，不携带账号 Cookie，不做 DRM 破解，也不上传本地文件。最近搜索、来源开关等状态保存在 WebView 的 localStorage 内。部分平台可能返回 HTTP 流，所以应用启用了明文流量；不使用时不会产生请求。
- **WebView 布局兼容**：AndroidView 首次布局时 Blink 可能把根元素百分比高度 / `100vh` 解析为 0，导致页面只显示背景。`index.html` 末尾会按 `window.innerHeight` 固定根节点像素高度，并在窗口或视觉视口尺寸变化时同步，因此首页、搜索结果、播放页和歌词页都能正常铺满。
- **稳定性边界**：这些接口并非官方开放 API，平台改版、地区限制、版权或 VIP 限制都可能导致某个来源暂时没有可播放地址；此时页面会提示解析失败或自动跳过，不影响本地音乐功能。

## 文件与删除语义

- **软件内副本**：`/data/user/0/com.catmusic.app/files/music/...`（无需 root 时，在歌曲信息面板可查看并复制完整路径）。卸载应用会连同副本一起删除。
- **导入来源**：只作为来源记录展示（文件名和 URI），软件不会在后台修改、移动或删除它。复制完成后，该歌曲不再依赖原文件权限。
- **在线存入播放器**：音频、封面和歌词都保存在应用私有目录，与导入歌曲使用相同的 Track 模型；在软件中删除会移除这些副本，清空音乐库也会一并清理，设备上的原文件不受影响。
- **仅保存到公共目录**：保存在 `音乐/CatMusic`（Android 8–9 位于应用专属外部音乐目录），由系统 DownloadManager 写入。CatMusic 的“从软件中删除”“清空音乐库”不会触碰这些文件；如需删除请在文件管理器中操作。
- **在软件中删除**：移除软件内音频副本、自定义封面、歌词缓存、播放队列中的对应项和所有歌单引用；听歌统计按歌曲 ID 保留，只有手动“重置统计”才会清空。
- **清空音乐库**：删除全部软件内音频副本、封面、歌词与歌单（包括在线存入播放器的歌曲），手机原始文件与仅保存在公共目录的在线文件不受影响。

## 实现说明

- 导入时先复制到临时文件，再原子重命名到以歌曲 ID 命名的稳定路径；重复导入会复用已有副本，不会重复占用空间。
- 元数据编辑保存在 CatMusic 的媒体库中，只影响软件内显示，不会改写音频文件的标签，更不会改动原文件。
- 歌单以歌曲 ID 引用曲目，删除歌曲时会自动清理所有歌单引用；删除歌单不会删除歌曲。
- 播放计时由**后台播放服务**负责：每 1 秒根据播放器实际 `isPlaying` 状态累加，切后台、锁屏都不会漏记。
- 封面播放页使用全幅模糊封面、居中封面卡、低密度尘点与底部玻璃控制坞；尘点动画只在 Draw 阶段读取，不触发整页重组。
- 原生沉浸式歌词页（音浪关闭）由渐变、封面光与冷色光晕组成，固定显示当前句附近的五行或四行；单曲偏移使用 `播放位置 − 偏移` 计算当前句，点按歌词跳转时再加回偏移。
- 音浪开启后的歌词页由 WebView 接管。`SonicLyricsScreen` 解析 `LyricsFile` 为 JSON 发送给页面；页面按收到的播放位置与时间戳插值当前句，避免两次状态更新之间的高亮滞后。播放/暂停、拖动进度、歌词跳转、校准和导入都通过 `@JavascriptInterface` 回到 Kotlin，并最终落到原来的 Media3 / MusicRepository。
- 鼓点律动在页面内使用一个短衰减包络（`beatEnvelope`）平滑 PCM 节拍信号，再写入 CSS 变量 `--lyric-beat`：当前句的原文与翻译分别放大、提亮，整块歌词平面也做极轻的呼吸缩放。同一个包络乘以可调的鼓点强度后驱动粒子着色器的 `uBeat`，并在地形节拍触发时补充一批光尘。强度只影响视觉，不改变音频播放；默认 65%，滑杆为 0 时不缩放、不额外生成光尘。
- 3D 歌词由舞台上的 `perspective` 和独立的 `.lyrics-tilt` 变换层实现，滚动层与 3D 层分离，互不覆盖 transform。音浪相机用四元数把基准偏移和朝向一起旋转，偏航绕世界 Y 保持无限；俯仰绕 X 受 `minPitchDeg`/`MAX_PITCH_DEG` 限制。最低俯仰不是写死的，而是在 `updateCameraForAspect()` 中由基准相机高度、目标点 y、缩放与横竖屏计算，保证相机至少高于地形 3 个单位；陀螺仪带来的额外俯仰也会在最终合成时再次钳制。Z 轴扭转只旋转相机自身，现在限制在 ±10°。歌词层始终位于 WebGL 画布上方，用 `sin(角度) × 最大倾角` 柔化跟随，水平/垂直/翻滚上限分别为 22°/14°/8°，所以旋转时歌词保持正面居中；歌词行额外使用 `translateZ` 分层，当前句还会跟随 `--lyric-beat` 向观察者浮起。手势使用 Pointer Events 并维护触点表：单指超过 7px 判定为调整视角，双指同时计算距离（缩放）与夹角（倾角），手势结束在 520ms 内抑制歌词点击；视角、缩放、倾角和歌词行数保存在 WebView 的 localStorage 中。
- 歌词行数由菜单滑杆控制 3–10 行。页面在取景框高度变化、安全区更新、校准面板开关和切歌后重新计算 `--lyric-font-size`、行距与行内边距，让目标行数完整落在音浪舞台内；窗口外的行保留布局但设为透明，避免滚动锚点跳动。
- 粒子是三组独立的 `THREE.Points`：远景星野只在着色器里做闪烁，方块微尘在 JS 中逐帧上浮/摆动并回收，节拍光尘来自固定的粒子池。每个点精灵的方形柔边、冷白/暖白混色与加法混合都由同一份 GLSL 着色器完成，不加载贴图、不请求网络。
- 粒子球是完全本地的 WebGL 点精灵渲染器，和 Three.js 地形共用同一份 `window.catmusic.audio` 数据但不共享渲染上下文。它把 10,000 个经纬点的位置、封面颜色、随机种子和大小一次性上传到 GPU，顶点着色器负责非镜像球面映射、旋转、透视、频段呼吸和鼓点散射；片元着色器绘制软边圆形光点并用加法混合叠亮。背景由另一个全屏片元着色器生成，封面暗部色、强调色和暗角都来自本机采样；球壳中心会随鼓点被推空，形成参考图的空心爆炸云。页面通过监听整体 `catmusic.audio / palette / playback` 并转调原始函数来接入，不修改 bundle 的原有行为。
- 粒子模式的性能控制：点缓冲是静态的，逐帧只更新几十个 uniform；画布 DPR 上限 2.0，暂停时停止 `requestAnimationFrame`，隐藏的 Three.js 地形在 `animate()` 中只更新歌词和进度、不提交任何 WebGL 绘制；切换回地形时从当前音频包络继续。两个 WebGL 上下文不同时绘制，粒子上下文在切到地形后也停止 requestAnimationFrame。
- 在线页的本地播放交接通过 `MusicBridge` 的 `pauseLocalPlayback` 完成：页面在 HTML5 `audio.play()` 前调用它，Bridge 把回调 `post` 到主线程，ViewModel 再发送 `FADE_TOGGLE` 自定义命令。只浏览在线页不会触发，因此切换标签不会打断本地音乐；真实开始在线试听时才做短暂淡出，避免两路声音叠加。进入在线标签时迷你播放器会隐藏，但后台播放和通知控制不受影响。
- 陀螺仪使用 Android 的 `TYPE_GAME_ROTATION_VECTOR`（无磁力计时更稳定，回退到 `TYPE_ROTATION_VECTOR`），取 pitch / roll 与开启时的基线比较，映射为小幅的 rotateX / rotateY，并和手指视角一起驱动 Three.js 相机环绕。菜单中的“陀螺仪灵敏度”是 0–200% 的线性增益（默认 100%），会先乘到姿态映射上再做角度限制；灵敏度保存在 WebView 的 localStorage。传感器只在歌词页处于 RESUMED 且开关打开时注册，暂停或退出即注销；该传感器不需要运行时权限，也不上传数据。
- 安全区由 `WindowInsets.safeDrawing` 以 dp 发送到页面，页面通过 CSS 变量同时避让竖屏的状态栏/手势条与横屏挖孔。硬件返回键先询问页面：菜单或歌词校准面板打开时只关闭该面板，没有可关闭层级时才退出歌词页。
- 歌词页 WebView 被销毁时会停止加载并 `destroy()`；音频数据循环绑定在 `repeatOnLifecycle(RESUMED)` 上，应用退到后台时不持续推送频段。R8 的 keep 规则保留了 `@JavascriptInterface` 方法。
- 封面播放页不再绘制原生音浪地形；横屏改为模糊封面 + 封面主色泛光 + 暗角 + 微尘的静态氛围，给封面和信息留出更干净的舞台。封面页仍读取 PCM 让微尘与光环轻微呼吸。
- 原生歌词页（关闭音浪时）也加入了鼓点脉冲：每帧读取 `AudioReactiveSignal` 的低频瞬态与节拍，合成短衰减包络，再通过 `graphicsLayer` 只缩放当前句，避免逐帧重组歌词列表。WebView 歌词页使用同一套驱动思路，但以 CSS 变量 `--lyric-beat` 同时缩放原文、翻译和整块歌词平面。
- 3D 歌词帧率保存在 SharedPreferences，并作为 URL 参数传给 WebView。页面用累加时间控制 `requestAnimationFrame`：30 / 45 是明确的低功耗上限，不参与分辨率自适应；无限制则每个 vsync 都渲染，屏幕刷新率是实际上限。
- 播放页与歌词页由两个 `AnimatedVisibility` 场景组成：封面场景淡出并轻微缩小，歌词场景淡入、上浮并放大到 1；离开歌词页时反向播放。原生歌词页与 WebView 歌词页再用 `Crossfade` 过渡，避免音浪开关时硬切渲染器。
- 全屏沉浸由 `MainActivity` 统一处理：`enableEdgeToEdge` 之后用 `WindowInsetsControllerCompat` 隐藏状态栏，并设置 `BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE`；窗口重新获得焦点时再次隐藏，避免从后台返回或文件选择器关闭后状态栏重新出现。只隐藏顶部状态栏，底部手势/导航区域仍然保留系统的正常安全间距。
- 进度条误触保护在 WebView 与 Compose 两侧使用同一套规则：按下时不立即跳转；横向位移超过触摸阈值且横向占优才开始拖动；只有起点位于细线附近 9–10px 内且几乎没有移动的轻点才直接跳转。竖向滑动和进度条附近的大块空白区域不会改变播放位置。WebView 使用 Pointer Events，原生播放页使用 `awaitEachGesture` 实现。
- 网页快捷方式保存在 SharedPreferences 的 `quick_links` JSON 中，最多 10 条，包含名称、网址、浏览器包名与显示名。浏览器列表通过带 `<queries>` 声明的 `ACTION_VIEW` 查询获得；打开时先尝试显式 `setPackage`，浏览器被卸载或拒绝时回退到系统默认，仍失败才提示“没有可用的浏览器”。网页由外部浏览器加载；应用自身的网络权限只交给「在线」页。
- 液态玻璃现在直接使用 QWEA0/Liquid-Glass-Android AAR v2.0.11（MIT），不再有手绘玻璃或 `GlassLight` 传感器。`LiquidGlassSurface` 由一层原生 `PassiveLiquidGlassView`（继承库的 `LiquidGlassView`，但拒绝全部触摸）和一层 Compose 内容组成；玻璃的 `backdropSource` 指向 Activity 根布局里的 `GlassBackdropView`。这避开了把玻璃直接采样 Compose 祖先时触发的 `Recording currently in progress` RenderNode 重入崩溃，同时保留 API 33+ 的 AGSL 透镜。测量后的圆角半径、染色与材质会同步给库；透明卡片走 `CLEAR`，深色播放器控制坞走 `REGULAR`，所有表面都启用传感器高光。
- 原生背景 `GlassBackdropView` 与 Compose 层是兄弟节点，作为玻璃的真实采样源和主界面可见背景。跟随歌曲封面时，它只有封面提取出的三色柔焦色场，不叠加任何星点、散景、线条或图片；DIY 预设仍保留各自的星点与氛围，但同样移除了声波圆环、斜向纹理和轨道弧线。预设风格与自定义图片在后台线程生成 Bitmap。只要存在当前歌曲（播放或暂停），背景就切换为由封面提取的三色色场：32×32 缩略图中取最暗的一批像素作为底色、最饱和的一批作为主色、最亮的一批作为高光，再用低透明度的大半径径向渐变和一条对角线性渐变铺满全屏，最后叠暗角。整个过程中**不会绘制封面图像**，因此背景只有颜色和渐变，没有封面文字/人物轮廓。没有封面时使用歌曲的确定性双色主题。退出当前歌曲后恢复用户选择的预设或自定义图片。每块玻璃还与 Compose 的 accent 细边叠加，以柠檬绿与冷紫蓝呼应 MusicDL 的新配色。
- 触摸兼容：`PassiveLiquidGlassView` 重写 `dispatchTouchEvent / onInterceptTouchEvent / onTouchEvent` 返回 `false`。没有这层处理时，AndroidView 中的原生玻璃会在部分桌面上抢走触摸，导致底部标签、卡片、迷你播放器和预设无法点击。已在 Xiaomi 15 上真机验证标签切换、卡片点击、背景预设选择、搜索聚焦、迷你播放器进入播放页、歌词按钮与定时暂停。
- 性能：Xiaomi 15（API 36、120 Hz）在主界面反复滚动并切换标签时，`dumpsys gfxinfo` 记录 1496 帧、0% Janky frames、0 次 Missed Vsync，50 / 90 / 99 分位为 8 / 10 / 13 ms，GPU 为 6 / 6 / 9 ms。
- 液态玻璃库以 MIT 许可分发，许可全文位于 `licenses/LIQUID-GLASS-ANDROID-MIT.txt`；依赖由 JitPack 在首次构建时下载，玻璃库本身在运行时不发起网络请求。
- 定时暂停由 `PlaybackService` 持有：通过 `MediaSession` 自定义命令 `SLEEP_TIMER_SET / SLEEP_TIMER_CLEAR / FADE_TOGGLE` 与 Compose 通信，倒计时状态放在进程内 `SleepTimerState` 的 `StateFlow` 中。前台服务和锁屏下计时不会中断；播放器音量在最后 `min(10s, max(1.5s, 时长/5))` 内逐步降到 0，然后 `pause()`。播放开始时统一从 0 淡入到 1，应用内暂停则先用 320ms 淡出再暂停。定时器在服务销毁时取消，不写入磁盘，避免重启后错误暂停。
- 主界面时钟位于 `LibraryHeader` 右上角：读取 `LocalDateTime`，显示 24 小时时分和按 `Locale.SIMPLIFIED_CHINESE` 格式化的日期/星期；协程精确等到下一分钟边界再刷新，只更新这两行文本，不触发音乐列表重组。旧版的大号模拟时钟卡片已移除。
- 应用图标前景为 MusicDL 的五根波形柱自适应矢量图，背景为 `#D9FF57` 纯色；`monochrome` 使用同一套波形，供 Android 13 主题图标取色。图标内容保持在自适应安全区内，并为 API 26–28 的圆形/方形启动器留有 PNG 回退。
- 一次性导入由 `MixedImporter` 完成：它先按扩展名/MIME 把一次选择拆成音频与旁车文件，音频仍交给 `MusicImporter` 复制和解析；歌词与封面使用规范化文件名（忽略大小写、空格、标点与括号内容，并去掉开头的音轨号）配对，再以歌曲标题兜底。文件夹导入优先按 SAF 文档 URI 中的相对目录配对，因此同目录的 `cover.jpg` 会作为整张专辑的封面；Downloads 等不暴露路径的提供器回退到文件名匹配。配对成功后才调用 `LyricsImporter` / `ArtworkTransformer` 写入私有目录。
- 主界面背景偏好保存在 SharedPreferences，自定义图片由 `HomeBackgroundStore` 做 EXIF 方向修正、最长边 2000px 压缩后写入 `files/backgrounds/`。所选预设或图片交给 `GlassBackdropView` 原生绘制，并在播放页切换为封面场景。赞赏二维码是 `res/drawable-nodpi` 中的本地图片，打开赞赏弹窗不涉及网络。
- 在线页由 Compose 的 `AndroidView` 承载一个独立 WebView，`file:///android_asset/musicdl/www/index.html` 只加载本地资源；`MusicBridge` 以 `Native` 名称注册 `search / resolve / download / downloadToLibrary / openExternal / toast` 方法。搜索和解析在线程池中调用纯 Java 的 `MusicApi`，回调用 `evaluateJavascript` 回到页面；`proguard-rules.pro` 保留了桥接类与方法，避免 R8 改名。
- 保存面板由在线页的 HTML/CSS 绘制，默认选中「存入播放器」，并根据 `resolved.lrc` 决定歌词选项是否可用。`downloadToLibrary` 在桥接线程里流式下载音频与封面，通过 `onLibraryProgress(requestId, phase, received, total)` 更新百分比；完成后把临时文件交给 `OnlineLibraryImporter`。后者以 `online|source|id` 生成稳定 UUID、移动音频到 `files/music`、保存 JPEG 封面与 UTF-8 LRC、读取实际时长，再调用 `MusicRepository.addTracks`，因此入库歌曲与手动导入歌曲共享播放、统计、删除和清理逻辑。
- 在线下载通过 `DownloadManager.Request` 设置标题、歌手描述、MIME、UA 与来源 Referer；Android 10+ 写入公共 `Music/CatMusic`，旧系统调用 `setDestinationInExternalFilesDir` 规避存储权限。系统下载通知与本地媒体通知互不干扰。
- 在线 WebView 在 `DisposableEffect` 中注销 `Native`、停止加载、跳转 `about:blank` 并销毁；`BackHandler` 先把返回交给页面的 `window.AppNative.handleBack()`，页面没有可关闭的层级时才退出到音乐馆。这样返回键、播放器和搜索页的层级与 MusicDL 原版一致。
- 因为 AndroidView 的首次布局会让 Blink 把根百分比高度 / `vh` 保活为 0，在线页在 `index.html` 末尾用 `window.innerHeight` 写入根节点的像素高度，并监听 `resize` 与 `visualViewport.resize`；这比依赖 `100vh` 更稳定。已在 Xiaomi 15 上验证首页、37 条搜索结果、在线播放、网易云歌词高亮与下载落盘。
- 数据库、副本、封面和歌词全部保存在应用沙盒内。卸载应用会删除全部数据，但不会删除设备上的原始音乐或公共 `音乐/CatMusic` 中的在线下载。

## 格式说明

大多数常见本地音频可直接播放。`WMA`、`APE`、`DSD` 等专有格式是否可用取决于文件编码和设备解码器；CatMusic 会复制并导入它们，无法解码时会自动跳到下一首。

1.18.1 主界面背景默认跟随当前播放的专辑：歌曲有封面时，四个主标签页与播放页统一使用该封面的模糊、增饱和色场；封面缺失时用歌曲的确定性双色主题生成同色柔焦背景。没有当前歌曲时才回退到 DIY 背景预设或自定义图片。背景仍由原生 `GlassBackdropView` 提供，玻璃实时采样它，因此换歌时整屏色彩与玻璃内外的折射同步更新。播放页收起、歌曲继续播放时背景保持专辑色；只有清空当前歌曲后才恢复用户选择的静态背景。已在 Xiaomi 15 真机验证换歌/暂停/关闭播放页/无封面歌曲，背景颜色与玻璃采样均正确，签名不变。
